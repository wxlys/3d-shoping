# 3D 打印服务系统（软件测试全流程项目）

基于 CRMEB v6（Apache-2.0）改版的 3D 打印服务系统，覆盖管理后台、Web 用户端、App 端，作为软件测试全流程练习项目。

## 目录

| 目录 | 说明 |
|---|---|
| `docs/` | PRD、测试计划、改版清单、数据库迁移脚本 |
| `deploy-crmeb/` | 云服务器 Docker Compose 部署包 |
| `crmeb-src/` | CRMEB v6 服务端源码（改造中） |

## 当前状态

- 云服务器部署完成：后端 API / 管理后台 / H5 均可用（http://8.148.5.169:18080）。
- 阶段 1 数据库改造完成：排单、设备、打印文件、询价单表 + 订单扩展字段 + 打印参数。
- 代码改造进行中：商品类型、订单状态机、支付 mock、询价/排单服务。
