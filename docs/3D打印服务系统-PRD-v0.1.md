## 1. 项目概述

### 1.1 背景与目标

以 3D 打印服务为业务场景，覆盖管理后台、Web 用户端、App 三个端。核心差异化能力：

1. 排单：自动排队 + 预计交付时间管理 + 管理员可改排期。
2. 秒杀：低价成品定时抢购，瞬时高并发。
3. 定制打印：模型文件上传、询价、报价、转订单全流程。

一期目标：三个端全流程可跑通，支持接口测试、UI 测试、性能测试（秒杀）、安全测试（越权/文件上传/输入校验）。

### 1.2 一期范围

包含：

- 管理后台：登录与账号安全、工作台、用户、商品、订单、询价单、排单、财务、系统设置。
- Web 用户端：注册/登录、商品浏览、购物车（仅成品）、秒杀、定制打印、订单、个人中心。
- App 端：与 Web 用户端功能一致，另加底部 Tab、分享（可选）；不做推送，仅站内信。

不包含：

- 优惠券、积分、营销活动。
- 快递配送、物流跟踪、用户收货地址（定制打印仅展示自提点地址）。
- 自提订单支持扫码或输入取件码核销。
- 支付渠道真实接入（一期全部 mock）。
- 周期结算/商家结算（仅订单流水与收支明细）。
- 树脂（SLA）打印、ABS、TPU 材料（本期仅提供 PLA/PETG）。

## 3. 核心业务规则

### 3.1 订单状态机（全端唯一口径）

| 状态 | 定义 | 进入条件 | 离开条件 |
|---|---|---|---|
| 待支付 | 已下单未支付 | 下单成功 | 支付成功；用户取消/支付超时/管理员取消 → 已取消 |
| 排队中 | 定制订单已支付，等待打印 | 定制订单支付成功，按支付时间入队 | 开始打印 → 制作中；退款审核通过 → 已退款 |
| 制作中 | 正在打印 | 到达预计开始时间 | 管理员标记打印完成 → 待取 |
| 待发货 | 普通成品/秒杀等待商家发货 | 普通快递订单支付成功 | 管理员发货 → 待收货；申请退款 → 退款审核中 |
| 待核销 | 普通成品/秒杀等待到店核销 | 普通自提订单支付成功 | 后台核销 → 待评价；申请退款 → 退款审核中 |
| 待取 | 定制打印完成后可到店自取 | 定制打印完成 | 用户确认收货/后台核销 → 待评价；申请退款 → 退款审核中 |
| 待评价 | 已收货，等待用户评价 | 用户确认收货或后台核销 | 用户完成评价；待评价满 7 天未评价自动 → 已完成 |
| 已完成 | 已评价或评价超时自动完成 | 用户完成评价或待评价满 7 天自动完成 | 终态 |
| 已取消 | 未支付取消 | 用户取消/支付超时/管理员取消 | 终态 |
| 退款审核中 | 退款申请待审核 | 定制（排队中）或普通订单（待发货/待核销）申请退款 | 审核通过 → 已退款；审核拒绝 → 回到原状态 |
| 已退款 | 退款完成 | 审核通过，mock 原路退回 | 终态 |

订单类型分支：

- 定制：待支付 → 排队中 → 制作中 → 待取 → 待评价 → 已完成。
- 成品/秒杀：不经过排队与制作；快递为待支付 → 待发货 → 待收货 → 待评价 → 已完成，到店自提为待支付 → 待核销 → 待评价 → 已完成。
- 普通商品还可由商家在待发货阶段改为到店自取：商家填写自取地点后进入待收货，用户到店取件并确认收货后进入待评价；该方式不属于虚拟发货。

订单关键字段：订单号、用户、类型、商品/SKU、数量、原价、实付、支付方式（mock）、状态、下单时间、支付时间、预计开始时间、预计交付时间、实际开始时间、完成时间、取件码、改价记录、进度备注、关联文件、退款信息。

### 3.2 询价单状态机

| 状态 | 定义 | 离开条件 |
|---|---|---|
| 待报价 | 用户已提交，等待管理员报价 | 管理员报价 → 已报价；用户取消 → 已取消 |
| 已报价 | 管理员已报价 | 用户确认 → 已确认；48 小时未确认 → 已过期；用户取消 → 已取消 |
| 已确认 | 用户确认报价 | 自动生成待支付订单（类型=定制） |
| 已过期 | 超时未确认 | 终态 |
| 已取消 | 用户主动取消 | 终态 |

规则：

- 文件校验通过后才能提交询价单。
- 提交内容：文件 + 尺寸档位 + 材料 + 数量。
- 管理员报价：金额 + 预计交付时间（由管理员根据实际业务情况手动设置）。
- 报价有效期默认 48 小时（可配）。
- 已过期不可确认。

### 3.3 文件状态机

| 状态 | 定义 | 离开条件 |
|---|---|---|
| 校验中 | 上传后异步校验 | 校验通过/失败 |
| 通过 | 可提交询价单、可复用下单 | 无 |
| 失败 | 校验未通过 | 用户重新上传替换 |

文件规则：

- 格式白名单（精确枚举）：stl、obj、3mf、stp、step。
- 大小上限默认 100MB（可配）；数量上限默认 50 个/用户（可配）。
- 服务端二次校验：后缀 + MIME + 文件头；前端校验仅体验，不可作为安全边界。
- 存储安全：文件名服务端随机重命名、存放于 Web 根目录之外、目录禁止执行权限。
- 清理任务：未被订单/询价单引用且超过保留期（默认 30 天）的文件定时删除。
- 仅“通过”状态的文件可提交询价单和“我的文件”复用下单。
- 同一文件在询价单“待报价/已报价”期间不可重复提交；询价任务进入“已确认”（本次询价完成）后，或询价单已取消/已过期、关联订单已退款/已取消后，可再次提交新的询价。

### 3.4 退款规则

- 可申请状态：定制订单仅“排队中”（开始打印前）；普通成品/秒杀仅“待发货”或“待核销”，已发货/已核销后不可申请。
- 申请需填写原因。
- 审核在后台完成：通过 / 拒绝（拒绝必填原因）。
- 退款金额 = 实付金额全额。
- 审核通过后：mock 原路退回；定制订单移出队列并重算后续排期；成品/秒杀回补库存。
- 退款审核中暂停自动完成计时。
- 已完成/已取消/已退款订单不可再申请退款。

### 3.5 排单规则（核心）

1. 入队：定制订单支付成功后，按支付时间入队（FIFO，无优先级）。
2. 设备数量：默认 1 台，后台可配置；多设备时取最早空闲设备。
3. 排单职责：排单仅维护设备、队列序号和当前排位，不再根据尺寸档位、材料、体积、填充率、流速、效率或调试时长自动计算预计交付时间。
4. 预计交付时间：以管理员报价时填写的“预计交付时间”为初始业务时间；管理员调整预计开始时间时，预计交付时间默认按相同时间位移同步，管理员也可直接手动覆盖。入队、开始打印、完成打印、取消/退款后的队列同步不得再次覆盖最终时间。
5. 尺寸档位校验：长宽高均 ≤ 256mm（拓竹 A1 构建体积 256×256×256 mm），体积 ≤ 对应档位上限；超出不可提交询价单。
6. 预计开始时间：仅作为后台排单参考，可由管理员调整“未开始打印”订单的预计开始时间；调整时默认同步预计交付时间，也可以在后台同时手动修改预计交付时间。
7. 取消/退款：移出队列，后续订单的队列序号和排位同步更新，并通知用户。
8. 打印完成由管理员在订单或排单中标记。

展示：

- 后台排单列表：序号、订单号、用户、文件、预计开始、预计交付、状态、操作（调整排期）。
- 用户端订单详情：当前排位、前方待处理数量、预计开始时间、预计交付时间。

### 3.6 秒杀规则

- 秒杀是商品类型（低价成品），不做独立活动模块。
- 秒杀字段挂在商品管理：秒杀价、开始时间、结束时间、秒杀库存、每人限购。
- 仅活动时间内可购买；倒计时展示；直接购买，不进购物车。
- 下单锁库存（原子操作防超卖）；支付超时/取消释放库存。
- 限购：同一用户同一秒杀商品整个活动期间累计购买数 ≤ 限购数（默认 1）。
- 活动结束后不可购买，展示“已结束”。
- 秒杀不叠加任何优惠。

### 3.7 支付与超时

- 支付方式：微信/支付宝，一期 mock 仅模拟支付成功；支付失败不单独模拟，异常场景通过“不支付 + 超时自动取消”覆盖。
- 支付超时默认 15 分钟（可配），超时自动取消订单并释放库存/移除队列。
- 支付回调需幂等，防重放。
- 后台可对待支付订单催付（发送站内信）。
- 定制打印完成进入“待取”状态时生成 6 位取件码；用户确认收货或后台使用取件码核销后进入“待评价”。

### 3.8 改价规则

- 仅“待支付”订单可改价。
- 改后金额 ≥ 0.01 元。
- 记录操作日志（原价、新价、操作人、时间）。
- 已支付订单不改价，如需调整走退款。

### 3.9 评价超时自动完成

- 待评价状态持续满 7 个自然日（从确认收货/后台核销时刻起 168 小时）且仍未评价，自动转为已完成。
- 退款审核中暂停计时。
- 定时任务每小时扫描（可配）。

### 3.10 消息通知

触发点：文件校验通过/失败、询价单报价成功、报价即将过期（可选）、支付超时提醒、催付、排单变化、打印完成、进入待取、确认收货/后台核销、退款申请提交（后台）、退款结果、评价超时自动完成。

渠道：仅站内信（Web 消息中心 + App 消息中心），不做 App 推送。

## 7. 非功能需求

### 7.1 安全

- 认证：密码加密存储（BCrypt）、token 过期、管理员登录锁定与会话超时。
- 鉴权：接口级鉴权；防水平越权与垂直越权。
- 输入：XSS、SQL 注入防护。
- 文件上传：白名单 + 服务端二次校验 + 存储安全（见 3.3）。
- 支付 mock：回调幂等、防重放。
- 日志与脱敏：操作日志完整；日志不记录密码/验证码明文；手机号脱敏展示。

### 7.2 性能（本地环境参考值）

| 场景 | 指标 |
|---|---|
| 秒杀下单 | 50 并发，无超卖，成功率 100%，TP95 ≤ 1s |
| 常规接口 | TP95 ≤ 500ms |
| 排单重算 | 100 单队列内 ≤ 2s |

## 10. 已确认事项

- 支付 mock：仅模拟支付成功，不做失败/超时分支；失败场景由支付超时自动取消覆盖。
- 消息渠道：仅站内信，不做 App 推送。
- 秒杀报表：不单独成页，并入订单/商品模块。
- 排单参数：参考拓竹 A1（构建体积 256×256×256 mm、热端最大流速 28 mm³/s）与官方材料最大体积速度（PLA 21、PETG 15 mm³/s）；默认值见第 8 章，均可配置。
- 材料范围：仅 PLA、PETG；TPU、ABS（A1 不推荐）与树脂（SLA 设备）不在本期。
- 取件码：6 位随机数字，进入待取状态时生成。
