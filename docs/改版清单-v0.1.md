- 秒杀基础模块：活动时间、秒杀价、库存、倒计时。
- 订单基础：下单、支付状态、取消、退款申请。
- 用户中心：资料、我的订单、消息中心（站内信）。
- 后台：管理员、角色权限（RBAC）、操作日志、系统设置、文件上传、财务流水。
- 前端框架：管理后台 Vue2、用户端 uni-app（H5/App 同源）。

## 二、裁剪（一期隐藏/关闭，不删代码）

- 其他：直播、客服（可选保留）、PC 端（可选保留）、分享（可选）、短信/微信模板消息依赖（改站内信）。
- 用户收货地址管理（自提不需要）。
- App 推送（一期不做，消息走站内信）。

## 三、改造（改现有）

### 1. 商品类型

- 类型扩展：成品、秒杀、定制打印（新增）。
- 定制打印：无库存、按单生产；规格组改为“尺寸档位 + 材料”。
- 尺寸档位：S=100、M=500、L=2000、XL=4000 cm³（标准体积，可配）。
- 材料：PLA、PETG（系数 1.0 / 0.71，可配）。

### 2. 秒杀

- 复用现有秒杀活动/商品配置，关闭其他营销。
- 确认/补齐：下单锁库存、每人限购、支付超时释放库存。
- 秒杀商品直接购买，不进购物车。

### 3. 订单状态机（核心改造）

- 定制：待支付 → 排队中 → 制作中 → 待取 → 已完成；另有已取消、退款审核中、已退款。
- 成品/秒杀：待支付 → 待取 → 已完成（不排队不制作）。
- 待取状态生成 6 位数字取件码。
- 确认收货：用户点击确认，或待取满 7 天自动完成（退款审核中暂停计时）。
- 退款限制：定制仅“排队中（开始打印前）”可申请；成品/秒杀仅“待取”可申请；完成后不可退。
- 订单详情增加：预计开始/交付时间、当前排位、前方数量、进度备注、取件码。

### 4. 支付（mock）

- 关闭微信/支付宝真实配置，替换为 mock 支付成功回调（幂等）。
- 支付超时默认 15 分钟，超时自动取消并释放库存/移除队列。

### 5. 消息通知（站内信）

- 触发点：文件校验结果、询价报价/过期、排单变化、打印完成、进入待取、退款结果、支付超时提醒。

### 6. 文件上传

- 上传上限调整为 100MB（PHP 与 CRMEB 配置同步）。
- 新增服务端校验：后缀白名单（stl/obj/3mf/stp/step）+ MIME + 文件头。
- 存储安全：随机文件名、Web 根目录外、uploads 目录禁止执行脚本。

### 7. 定时任务

- 支付超时取消（15 分钟）。
- 报价过期（48 小时）。
- 自动收货（7 天）。
- 过期文件清理（30 天，未被引用）。

## 四、新增（自定义开发）

### 4.1 数据表

| 表 | 关键字段 |
|---|---|
| eb_print_device | 名称、型号（A1）、构建体积、状态、营业开始/结束、设备调试时长 |
| eb_print_queue | 订单号、设备、队列序号、预计开始/结束、实际开始/结束、状态、调整人/时间 |
| eb_print_file | 用户、文件名、存储名、扩展名、大小、状态（校验中/通过/失败）、失败原因 |
| eb_inquiry | 用户、文件、尺寸档位、材料、数量、状态（待报价/已报价/已确认/已过期/已取消）、报价金额/人/时间、有效期、转订单号 |
| order 扩展字段 | is_print、pickup_code、expected_start_at、expected_deliver_at、queue_status、progress_note、file_id、size_level、material |
| system_config 扩展 | 营业时间、调试时长、设备数量、速度/填充/效率系数、档位体积、材料系数、支付超时、报价有效期、自动收货天数、文件大小/数量/保留期 |

### 4.2 后端服务/接口

- 文件校验服务（上传后异步校验）。
- 询价单服务：提交 → 报价 → 确认转正式订单 → 过期/取消。
- 排单服务：支付成功入队、预计时间计算、取消/退款/改排期后重算、通知。
- 订单扩展：取件码生成、进度备注、确认收货、自动完成。
- 打印参数配置接口。

### 4.3 管理后台（Vue2）

- 新增“询价单管理”：列表、详情、报价、转单、过期处理。
- 新增“排单管理”：队列列表、调整排期、设备与参数配置。
- 商品编辑支持“定制打印”类型与尺寸/材料规格。
- 订单管理增加定制字段、进度备注、取件码展示。
- 菜单权限注册；隐藏裁剪模块入口。

### 4.4 用户端（H5/uni-app，App 同源）

- 定制流程：上传文件 → 校验状态 → 选尺寸/材料/数量 → 提交询价 → 查看报价 → 确认 → 支付。
- 我的询价单：报价确认、过期提示。
- 我的文件：仅“通过”状态可复用下单。
- 订单详情：排位、预计交付、进度、取件码、确认收货、退款申请。
- 购物车仅成品；秒杀直接购买；隐藏营销/分销/充值入口。

- CRMEB 要求保留版权标识，改版代码继续保留原作者版权声明。
- 秒杀并发依赖 Redis，确认现有扣库存与限购实现后再压测。
- uni-app App 端构建需要 HBuilderX，排期预留。
- 定时任务依赖 CRMEB 的队列/定时组件，需确认可用后接入。
