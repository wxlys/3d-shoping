普通成品/秒杀订单按配送方式分流：快递为“待支付 → 待发货 → 待收货 → 待评价 → 已完成”；下单时选择到店自提为“待支付 → 待核销 → 待评价 → 已完成”。后台还可将待发货普通订单改为到店自取，填写地点后进入待收货，由用户确认收货进入待评价。快递订单不能使用核销码；定制打印仍使用独立排单和 6 位取件码流程。

## 三、改造（改现有）

### 1. 商品类型

- 类型扩展：成品、秒杀、定制打印（新增）。
- 定制打印：无库存、按单生产；规格组改为“尺寸档位 + 材料”。
- 尺寸档位：S=100、M=500、L=2000、XL=4000 cm³（标准体积，可配）。
- 材料：PLA、PETG（系数 1.0 / 0.71，可配）。

### 2. 秒杀

- 复用现有秒杀活动/商品配置，关闭其他营销。
- 确认/补齐：下单锁库存、每人限购、支付超时释放库存。
- 秒杀商品直接购买，不进购物车。

### 3. 订单状态机（核心改造）

- 定制：待支付 → 排队中 → 制作中 → 待取 → 待评价 → 已完成；另有已取消、退款审核中、已退款。
- 成品/秒杀：不排队不制作；快递为待支付 → 待发货 → 待收货 → 待评价 → 已完成，到店自提为待支付 → 待核销 → 待评价 → 已完成。
- 定制打印完成后生成 6 位取件码；普通自提继续使用下单时生成的 12 位核销码，普通快递不生成核销码。
- 确认收货：用户点击确认或后台核销后进入待评价；待评价满 7 天未评价自动完成（退款审核中暂停计时）。
- 退款限制：定制仅“排队中（开始打印前）”可申请；普通成品/秒杀仅“待发货”或“待核销”可申请，发货/核销后不可退。
- 订单详情增加：预计开始/交付时间、当前排位、前方数量、进度备注、取件码。

### 4. 支付（mock）

- 关闭微信/支付宝真实配置，替换为 mock 支付成功回调（幂等）。
- 支付超时默认 15 分钟，超时自动取消并释放库存/移除队列。

### 5. 消息通知（站内信）

- 触发点：文件校验结果、询价报价/过期、排单变化、打印完成、进入待取、退款结果、支付超时提醒。

### 6. 文件上传

- 上传上限调整为 100MB（PHP 与 CRMEB 配置同步）。
- 新增服务端校验：后缀白名单（stl/obj/3mf/stp/step）+ MIME + 文件头。
- 存储安全：随机文件名、Web 根目录外、uploads 目录禁止执行脚本。

### 7. 定时任务

- 支付超时取消（15 分钟）。
- 报价过期（48 小时）。
- 评价超时自动完成（7 天）。
- 过期文件清理（30 天，未被引用）。
